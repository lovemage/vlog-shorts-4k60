# Cover recipe

1. **Art.** Generate a vertical illustration (1280×1920 or larger) of the place or the best moment with
   the image model the user picked. Leave space for the title in the top third. Never ask the model for
   the title text; generated lettering is unreliable, especially CJK and Thai.
2. **Title in code.** Use Pillow with the project fonts (`assets/fonts/`) to add a series ribbon, a big
   hook headline on a torn-paper label, a pill with the event name, and a round sticker (e.g. "9 DAYS").
   Give text a stroke and drop shadow so it stays readable as a small thumbnail.
3. **Outputs.** Make a 9:16 1080×1920 JPG for Shorts/TikTok and a 3:4 1080×1440 centre crop, then check
   that the headline survives the IG/TikTok profile-grid crop.
4. **Check.** View both files at thumbnail size (about 200 px wide) before handing them over.
