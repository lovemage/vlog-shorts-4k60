# Interactive POV Short-Form Script Rules

1. **Immediate Continuity Hook (0–5s)**: Pay off the previous episode's winning comment choice immediately in frame 1.
2. **Deadpan Comedy + Clear Cause & Effect**: Include 1–2 sharp viral/deadpan comedy beats; every new prop, character, or twist must be visually clear. Keep expressions deadpan (no smiling) in disaster/absurd settings.
3. **Distinct Voices & Binary Cliffhanger**: Every character should be recognizable without name tags. End on an urgent cliffhanger + a 4-second binary choice card (`1` vs `2`) so viewer comments decide the next episode.
